# 2026.246.1624 — feat(record): add the gif method — render .cast recordings to animated GIFs via agg

## Summary

Adds the **`record: gif`** method to the record check verb: renders a STOPPED
terminal recording (.cast) to an animated GIF with agg (asciinema/agg v1.9.0,
installed by the asciinema candy — opencharly/layer-asciinema#3) and copies the
.gif to the host artifact path — the same GetFile-pull shape as `record: stop`.

- **schema/record.cue**: "gif" added to the method enum; new optional fields
  (theme, font_size, speed, idle_time_limit, fps_cap, select, cols, rows, no_loop,
  last_frame_duration, renderer) mapping 1:1 to agg's CLI flags.
- **params/cue_types_gen.go**: regenerated via `cue exp gengotypes` (pinned cue
  v0.16.1) + the schemagen retag transform — also fixes pre-existing comment drift
  (the committed file was stale vs the schema).
- **methods.go**: `recordGif` (verifies the .cast exists on the venue, checks agg
  is installed, runs `agg <options> <cast> <gif>`, GetFile-pulls the .gif to the
  artifact path), `aggArgs` (deterministic option builder), dispatch case, and the
  `gif` required-modifier (artifact).
- **methods_test.go**: TestAggArgs (14 cases incl. full option set + determinism)
  and the gif required-modifier cases.
- **charly.yml**: description updated (list, start, stop, cmd, gif + agg options).

The record skill docs (gif method, agg tool row, prerequisites) land separately in
opencharly/layer-charly-check#9.
